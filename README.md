# Online Real Estate Management System

## Project Overview
The Online Real Estate Management System is a web-based application designed to manage property listings, tenant applications, and rental agreements in one place.

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript

## Main Features
- **User Registration and Login:** Users can register and log in.
- **Property Management:** View and manage property listings.
- **Property Search:** Tenants can search for available properties.
- **Application Management:** Admin can manage tenant applications.
- **Rental Agreements:** Manage rental agreement details.
- **Admin Dashboard:** Provides administrative functions.

## Requirements
- Java Development Kit (JDK)
- MySQL Server
- An IDE such as Visual Studio Code or IntelliJ IDEA
- Maven (or the included Maven Wrapper)

## How to Run the Project
1. Download or clone this repository.
2. Open the project in your IDE.
3. Create the required MySQL database.
4. Configure your database name, username, and password in the project's application configuration file.
5. Make sure the database tables are created according to the project configuration.
6. Run the Spring Boot application.
7. Open your browser and visit `http://localhost:8080/`.

**Note:** Database configuration and table setup must match the actual source code.
